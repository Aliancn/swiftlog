## About

SwiftLog is a lightweight, high-performance platform for collecting, storing, and analyzing logs from script executions.

**Key Features:**
- Zero-intrusion log collection
- Real-time streaming
- AI-powered analysis
- Full-featured REST and WebSocket APIs
- Production-ready deployment
