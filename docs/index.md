## What is SwiftLog?

SwiftLog is a lightweight, high-performance platform for collecting, storing, and analyzing logs from script executions. It provides:

- **Zero-Intrusion Collection**: Wrap any command with `swiftlog run`
- **Real-Time Streaming**: Watch script output live in the web interface
- **Accurate State Tracking**: Captures exact exit codes and execution status
- **AI-Powered Analysis**: Automatic report generation using OpenAI
- **Full-Featured API**: RESTful API and WebSocket support for integrations
